# About Me

Hi, I'm **Thanh Le** (Lê Quang Thành) 👋

I'm a passionate software engineer with expertise in Linux systems, embedded development, networking, and DevOps. Currently working at Amazon, I focus on building robust and scalable solutions for complex technical challenges.

## Areas of Expertise

- **Linux Systems**: System administration, kernel optimization, and performance tuning
- **Embedded Systems**: Microcontroller programming, IoT devices, and hardware-software integration
- **Networking**: Network protocols, Docker networking, virtual interfaces, and network security
- **DevOps**: CI/CD pipelines, containerization, infrastructure as code, and automation
- **Robotics**: Autonomous systems and sensor integration

## Professional Background

With years of experience in software development and system engineering, I've worked on various projects ranging from embedded firmware to large-scale distributed systems. My approach combines theoretical knowledge with practical implementation to deliver efficient solutions.
